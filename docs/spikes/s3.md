# S3. Surfer в изолированном iframe

- Дата: 2026-10-28
- Вопрос ([spikes-and-risks.md](../../specs/plan/spikes-and-risks.md)): встраивается ли web-версия Surfer на отдельном origin в iframe с `sandbox="allow-scripts"` без `allow-same-origin`; загрузка FST из байтов, переданных через `postMessage`; программное добавление сигналов, курсор, зум, тема; размер бандла и время загрузки; открывается ли FST текущей версии Verilator.
- Критерий успеха: все действия FR-WAV-01/03/04 выполняются из родительской страницы через адаптер; загрузка < 2 с.
- Итог: **критерий выполнен** при двух условиях. Палитру сайта (FR-WAV-04) web-Surfer задаёт только встроенными темами, поэтому две темы Apparatica добавляются в Surfer при сборке. Холодная загрузка укладывается в 2 с на канале от 20 Мбит/с (1,9 с вместе с FST), повторная — 0,3–0,4 с. Решение по темам принял заказчик.
- Стенд: ветка `spike/s3-surfer-embed`, каталог `spikes/s3-surfer-embed/` (в основную ветку не переносится).

## Условия

Surfer v0.7.0 (последний релиз, 2026-04-27; коммит `bd749b1f`), собран как в CI Surfer (`pages_build`): Rust 1.95, trunk 0.21.14 (он же ставит wasm-bindgen 0.2.118 и wasm-opt 123), `--release --features accesskit`. Сборка в Docker на VPS AEZA (4 vCPU) — 3,5–5,3 мин.

Своя страница `waveview` вокруг неизменённой сборки: `index.html` без аналитики и service worker из страницы Surfer, `adapter.js` (адаптер, свой протокол `postMessage`), без встроенных скриптов. Два origin на одной машине: родитель `http://localhost:8000`, `waveview` — `http://127.0.0.1:8001` с CSP из NFR-SEC-07 (`default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self'; connect-src 'self'; frame-ancestors <родитель>`). Родитель скачивает FST и передаёт байты в iframe (`postMessage` с передачей `ArrayBuffer`).

FST — от `judge run` на мутантах `sync-fifo` (m01, m03) образом профиля `2026.10.3` (Verilator 5.052): окно ошибки 47 тактов, 2,5 КБ. Большие FST — полная трасса стенда S5 на 50 тыс. – 4 млн тактов. Браузер — Edge 156 (Chromium) через Playwright, Windows 11, Ryzen 7 2700X. Медленный канал — сервер отдаёт ответы с заданной скоростью и задержкой 40 мс: эмуляция сети в DevTools не действует на iframe, который Chromium вынес в отдельный процесс.

## Результаты

### Интерфейс управления

| Проверка | Результат |
|---|---|
| Что есть у web-Surfer для встраивающей страницы | `inject_message(json)` — любое сообщение `Message` (официально нестабильно); WCP (Waveform Control Protocol) через функции `start_wcp`, `handle_wcp_cs_message`, `next_wcp_sc_message` — версионированный протокол с ответами и событиями; `postMessage`-команды `integration.js` (`LoadUrl`, `ToggleMenu`, `InjectMessage`) |
| Загрузка из байтов | `LoadFromData` через `inject_message`: байты как JSON-массив чисел. Окно ошибки 2,5 КБ — 30–35 мс внутри iframe, 50–110 мс от родителя |
| Загрузка через `blob:`-URL | не работает: Surfer качает URL через reqwest, тот отклоняет схему `blob:` |
| WCP `load` | принимает только `http(s)://` или путь к файлу — для байтов не годится |
| Сигналы | WCP `add_variables` с полными именами (`tb_top.exp_rdata`) — 11 сигналов за 60–70 мс; неизвестное имя Surfer молча пропускает (в ответе меньше `ids`) |
| Цвет сигнала | WCP `set_item_color` с именем цвета из таблицы `[colors]` темы |
| Курсор на такте расхождения | WCP `set_cursor` — 6–14 мс |
| Зум и центр | WCP `set_viewport_range`, `set_viewport_to`, `zoom_to_fit` — 6–19 мс |
| Метка «такт N» | WCP `add_markers` — 11 мс |
| Отображаемые имена | `ItemNameChange` через `inject_message` по индексу из `index_of_name`; кириллица отображается |
| Тема | `SelectTheme` через `inject_message`, 2–4 мс; только встроенные темы по имени — свою палитру во время работы не задать ни сообщением, ни конфигурацией (`SetConfigFromString` тоже принимает только имя темы) |
| Свои темы при сборке | две TOML-темы из `tokens.css` в `themes/` и одна строка в список встроенных тем (`libsurfer/src/config.rs`): такт `ac`, линии `tx`, шины `in`, ожидаемые значения `mu`, курсор `er`, фон `ed` — работает в обеих темах |
| Скрыть меню, панели, строку состояния | `SetMenuVisible`, `SetToolbarVisible`, `SetSidePanelVisible`, `SetOverviewVisible`, `SetStatusbarVisible` |
| Готовность и окончание загрузки | WCP: приветствие → ответное приветствие со списком команд; событие `waveforms_loaded` при любой загрузке, не только через WCP |
| Ошибка разбора файла | WCP ничего не присылает: ошибка только в журнале Surfer. Предыдущий файл остаётся на экране (`waves_loaded() = true`) |
| Паника Surfer | вызывает глобальную `window.on_surfer_error(msg)`; после неё просмотрщик мёртв |
| FST Verilator 5.052 | открывается (в 0.7.0 исправлено чтение нового варианта FST Verilator); иерархия `tb_top.*`, `tb_top.dut.*`, `apx_tb_pkg.*` |
| Ось времени | в единицах FST (`1ps`): такт 30 из `tb_result` — фронт `#295`, проверка на спаде `#300`. Номеров тактов на оси Surfer не показывает |

### Изоляция

| Проверка из кода внутри iframe | Результат |
|---|---|
| `self.origin` | `null` |
| `parent.document`, `top.location = …` | `SecurityError` |
| `document.cookie`, `localStorage` | `SecurityError`; Surfer без хранилища работает (настройки не сохраняет) |
| `fetch` к сайту и наружу | заблокирован (CSP `connect-src 'self'`) |
| `window.open` | `null` (нет `allow-popups`) |
| `waveview` без `Access-Control-Allow-Origin` | не загружается ничего: модуль `adapter.js` и `surfer_bg.wasm` запрашиваются от origin `null` в режиме CORS |
| CSP `'self'` в iframe с origin `null` | сопоставляется с адресом страницы: скрипты и WASM своего origin грузятся |
| Preflight `OPTIONS` для WASM | на этой машине — да: Kaspersky добавляет к `fetch` заголовок `x-kl-ajax-request`. Без ответа на `OPTIONS` просмотрщик не открывается |
| Испорченные FST: пустой, 4 КБ случайных байтов, обрезанный наполовину, 60 файлов с 4 случайными байтами | 9 загрузились, 44 — ошибка разбора (ответа нет, выручает тайм-аут), 10 — паника Surfer. Родительская страница во всех случаях работает; после паники iframe пересоздаётся |

## Выводы

1. Встраивание по ADR-0004 работает: Surfer в iframe с `sandbox="allow-scripts"` на своём origin, родитель передаёт байты и управляет просмотром; код внутри iframe не достаёт до cookie, DOM и сети сайта, а паника Surfer на испорченном FST не задевает страницу задачи.
2. Опора адаптера — WCP: он версионирован, отвечает на каждую команду и сообщает о загрузке. Нестабильный `Message` нужен там, где у WCP команды нет: загрузка байтов (`LoadFromData`), тема, панели, отображаемые имена. Этот набор — пять сообщений — проверяет регрессия при обновлении Surfer.
3. Палитру сайта можно получить только сборкой со своими темами. Правка — две TOML-темы и одна строка в списке встроенных тем; Surfer становится изменённой версией (EUPL-1.2, ADR-0012). Предложение в upstream — команда WCP или сообщение «тема из TOML» — позволит убрать правку.
4. Узкое место загрузки — 3 МБ WASM. На канале 20 Мбит/с холодный старт 1,8 с, с FST — 1,9 с; повторно — 0,3–0,4 с. `opt-level = "z"` экономит 0,25 с на холодном старте, но вдвое замедляет добавление сигналов на больших трассах — оставляем сборку как у Surfer. Отключение функций по умолчанию почти не уменьшает размер.
5. Такт расхождения переводит во время только тестбенч: связь такта со временем FST зависит от периода и фазы такта конкретного тестбенча. Ось Surfer показывает время (`ps`), а не такты, как на макете.
6. Ошибка разбора и неизвестный сигнал не дают ошибки по WCP: адаптер сам ставит тайм-аут, сверяет число добавленных сигналов и пересоздаёт iframe, иначе на экране остаётся прошлый файл.
7. Порог «Слишком большой файл» определяется временем разбора — около 0,35 с на МБ. Окно ошибки — единицы КБ; порог касается только полной трассы теста (FR-WAV-05).

## Рекомендации для T1.17

- **Сборка.** Dockerfile стенда (тег и коммит Surfer, версия trunk закреплены) с темами `apparatica-light` и `apparatica-dark`; результат — статика в бакет `waveview` по пути с версией, `Cache-Control: immutable`. Версия Surfer и тем — часть `ToolchainProfile` (ADR-0004).
- **Страница `waveview`** — своя: `index.html`, `adapter.js`, CSS, без встроенных скриптов, аналитики и service worker; `window.on_surfer_error` сообщает родителю о панике.
- **Заголовки origin `waveview`** (Caddy перед сайтом Garage): CSP как на стенде с `frame-ancestors` сайта; `Access-Control-Allow-Origin: *`; ответ на `OPTIONS` (антивирусы добавляют заголовки); `application/wasm`; сжатие (`encode zstd gzip` или заранее сжатый brotli). Правило CORS бакета `artifacts` для origin `waveview` не нужно: iframe с origin `null` сам ничего не скачивает.
- **Протокол адаптера** (версия 1): `load`, `signals` (с цветами), `rename`, `cursor`, `range`, `center`, `fit`, `marker`, `theme`, `chrome`; ответы `ready`, `loaded`, `ack`, `error`, `crashed`. Родитель принимает сообщения только от `iframe.contentWindow` (origin у них `null`), iframe — только от `window.parent`; отправка с `targetOrigin "*"` допустима: передаётся только собственный FST пользователя.
- **Состояния `WaveformPanel`.** iframe создаётся при открытии панели результатов, а не по клику на вкладку, — к моменту падения теста просмотрщик готов. Ошибка — тайм-аут загрузки (5 с для окна), паника или отказ: iframe пересоздаётся, «Повторить» повторяет загрузку. Порог «Слишком большой файл» — в конфигурации; 5 МБ — около 2 с разбора.
- **Курсор.** `apx_tb_pkg` записывает в `tb_result.jsonl` время расхождения в единицах FST (`$time` на проверке), судья передаёт его вместе с тактом; адаптер ставит курсор и метку «такт N», окно `[T−64, T+16]` переводится во время так же. Ось Surfer остаётся в единицах времени: номера тактов — в шапке панели («такты 139–147») и в метке.
- **Сигналы.** Порядок ADR-0004: такт, входы, пары `<port>` / `exp_<port>`; `exp_<port>` показывается как «`<port>` ожидалось» цветом `Expected`, шины — `Bus`, такт — `Clock`. Колонка имён Surfer узкая: длинные имена обрезаются.
- **Регрессия образа** (ADR-0004): FST эталонной задачи открывается в закреплённой сборке через адаптер в headless-браузере — заодно проверяются пять сообщений `Message`.
- **Не проверено:** Firefox и Safari (нужен WebGL2), экранные дикторы (`accesskit` включён в сборку).

## Что меняется в документах

- ADR-0004: принято; уточнены адаптер (WCP + пять сообщений), загрузка байтов, темы при сборке, заголовки origin `waveview`, время курсора.
- ADR-0012: Surfer распространяется изменённым — со своими темами; изменения под EUPL-1.2 в нашем репозитории.
- specs/03 §5: Surfer — на отдельном origin, а не в `web/public` того же origin (устаревшая строка до ADR-0004).
- spikes-and-risks: R4 понижен.
