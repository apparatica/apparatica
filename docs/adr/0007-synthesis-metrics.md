# ADR-0007. Синтез и метрики: yosys-slang, Nangate45, OpenSTA

- Статус: Принято (PDK — Nangate45, решение ОВ-3); детали скрипта уточняет спайк S4
- Дата: 2026-10-24
- Связано: бриф §5; FR-SYN-*; 07 §2.4

## Контекст
Нужны сравнимые ASIC-метрики: площадь, число ячеек и триггеров, задержка критического пути, логическая глубина; признаки латчей и несинтезируемого кода. Родной SV-фронтенд Yosys слаб — бриф предписывает yosys-slang. Метрики должны быть детерминированными (рейтинг, кэш).

## Решение
- **Фронтенд:** `read_slang` (yosys-slang) с флагами `--no-synthesis-define --no-default-translate-off-format`: по умолчанию yosys-slang неявно определяет `SYNTHESIS` и понимает комментарии `translate_off`, а это позволило бы решению выглядеть для синтеза иначе, чем для симуляции. На вход подаётся только канонический текст без комментариев и директив (specs/07 §2.1). Параметры — из `stages.synth.params`.
- **Библиотека:** Nangate45 / FreePDK45 Open Cell Library. Причины: простая однокорнерная liberty, площади и задержки «учебного» масштаба (FIFO из брифа ≈ 836 µm², 0,84 нс — порядок совпадает именно с 45 нм), широко используется в OpenROAD-flow-scripts. Выбор PDK пользователем — задел на будущее; метрики сравнимы только в пределах одной библиотеки.
- **Маппинг:** `synth -flatten` → (сохранение нетлиста на внутренних вентилях Yosys для этапа `netlist_sim`) → `dfflibmap -liberty` → `abc -liberty` → `hilomap`, `splitnets -ports`, `opt_clean`; `stat -liberty` → площадь и ячейки; триггеры — ячейки DFF из liberty; нетлист для STA — `write_verilog -noexpr -noattr`.
- **Симуляция нетлиста** (specs/07 §2.5) — обязательное условие попадания в рейтинг: синтезированная схема проходит тот же тестбенч с тем же сидом. Нетлист берётся до привязки к Nangate45, поэтому модели ячеек не нужны.
- **Задержка:** OpenSTA по смапленному нетлисту с фиксированными ограничениями из образа (не из решения): клок на порт с ролью `clock`, период из конфига, `set_driving_cell` и `set_load` на все порты, задержки входов и выходов 0; отчёт худшего пути (reg→reg, in→reg, reg→out); для комбинационных задач — in→out. `ltp` — дешёвая логическая глубина как дополнительная метрика.
- **Латчи:** при `forbid_latches` (по умолчанию да) — этап `failed`.
- **Детерминизм:** фиксированный скрипт, один поток ABC, закреплённые версии; S4 проверяет совпадение метрик в 20 прогонах и на разных машинах.

## Лицензия Nangate45 — помнить
Лицензия Nangate Open Cell Library разрешает распространение с сохранением уведомления, но:
- запрещает измерять библиотеку и сравнивать её с другими библиотеками (benchmarking);
- помечена «not intended for commercial use»; Fedora признала её несвободной.

Для бесплатного некоммерческого проекта это приемлемо (решение заказчика, 2026-10-24). Обязательства:
1. В образе тулчейна рядом с liberty лежит её `LICENSE`; T3.1a (образ с синтезом) проверяет это в критериях готовности.
2. Проверка лицензий в CI содержит явное исключение для Nangate45 со ссылкой на этот ADR (NFR-MAINT-07).
3. При будущем выборе PDK пользователем интерфейс **не показывает сравнения метрик между библиотеками**.
4. Коммерческие форки и инстансы должны сами оценить лицензию; это сказано в `docs/deployment.md` и README образа.
5. Риск R15 в реестре рисков; запасные варианты — ASAP7 или sky130.

## Последствия
- В образе тулчейна: Yosys, yosys-slang, ABC, OpenSTA, liberty — S4 измеряет время синтеза типовой задачи (цель < 5 с).
- Метрики пригодны для сравнения решений, но не являются sign-off; в UI — пояснение «оценка после синтеза на открытой библиотеке 45 нм».

## Альтернативы
- sky130 — реальный техпроцесс, но тяжёлая liberty и много корнеров; ASAP7 — предиктивный 7 нм, единицы в пс.
- Задержка только по ABC (`abc -D`, `sta` Yosys) — проще, но менее точна для путей через триггеры; запасной вариант, если OpenSTA дорог.
- Только `ltp` (глубина в ячейках) — без PDK, но не отражает реальную задержку и площадь.
