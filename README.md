# Apparatica

Открытый тренажёр по RTL-разработке на SystemVerilog — «LeetCode для цифровой логики». Пишете модуль в браузере, а платформа проверяет его симуляцией, синтезом и формальными методами, показывает временные диаграммы и сравнивает решения по площади и задержке.

Проект в разработке: идёт фаза Ф0 «Фундамент» ([план](specs/plan/roadmap.md)).
