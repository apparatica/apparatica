Реализуйте синхронную очередь FIFO на `DEPTH` слов по `WIDTH` бит. Запись и чтение идут по одному тактовому сигналу `clk`.

По переднему фронту `clk`:

- если `rst_n = 0`, очередь опустошается (сброс синхронный; содержимое памяти обнулять не нужно);
- если `push = 1` и очередь не полна, `wdata` добавляется в конец;
- если `pop = 1` и очередь не пуста, слово с вершины удаляется;
- `push` и `pop` в одном такте выполняются оба, если каждый допустим сам по себе: в полной очереди выполняется только `pop`, в пустой — только `push`. Запись в полную очередь и чтение из пустой игнорируются.

Выходы:

- `rdata` — слово на вершине очереди, видно сразу, без отдельного такта чтения (first-word fall-through): `pop` удаляет то слово, которое сейчас на `rdata`. Пока очередь пуста, значение `rdata` не важно;
- `empty = 1`, когда в очереди нет слов; `full = 1`, когда в ней `DEPTH` слов.

Параметры: `WIDTH` — разрядность слова (по умолчанию 8), `DEPTH` — ёмкость, степень двойки (по умолчанию 16).
