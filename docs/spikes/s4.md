# S4. Метрики синтеза

- Дата: 2026-11-06
- Вопрос ([spikes-and-risks.md](../../specs/plan/spikes-and-risks.md)): yosys-slang с `--no-synthesis-define --no-default-translate-off-format` на 5 демо-задачах; Nangate45; OpenSTA с фиксированными `set_driving_cell`/`set_load` против `abc -D`/`sta`; подготовка нетлиста (`hilomap`, `splitnets -ports`, `write_verilog -noexpr`); симуляция нетлиста на внутренних вентилях Yosys в Verilator (корректность и стоимость); время синтеза; детерминизм (20 прогонов, 2 машины); способ поставки liberty с `LICENSE`.
- Критерий успеха: метрики совпадают побайтно; синтез типовой задачи < 5 с; симуляция нетлиста проходит для эталонов и ловит подставной расходящийся нетлист; скрипт зафиксирован.
- Итог: **критерий выполнен.** Скрипт ADR-0007 работает с четырьмя уточнениями: yosys-slang теперь встроен в Yosys, неполный `always_comb` даёт комбинационную петлю вместо латча, `ltp` нужно исключить триггеры liberty, а обёртке нетлиста нужен `-Werror-USERFATAL`. Отдельная находка — лицензия Nangate45 (открытый вопрос ОВ-21).
- Стенд: ветка `spike/s4-synth-metrics`, каталог `spikes/s4-synth-metrics/` (в основную ветку не переносится).

Образ стенда — `apparatica-toolchain:dev` (профиль `2026.10.3`) и поверх него:

Образ вырос с 756 МБ до 1,09 ГБ (Yosys 89 МБ, OpenSTA 105 МБ, liberty 6,5 МБ). Контейнеры — с флагами песочницы класса `light`: `--network=none --read-only --cpus=2 --memory=2g`, каждый шаг в новом контейнере. Машины: Docker Desktop (WSL2) на рабочей машине и VPS из [S2](s2.md) (AEZA, Ryzen 9 7950X3D, 4 vCPU) под `runc` и `runsc`. Период клока `clock_period_ns = 2,0`, параметры — значения по умолчанию из `problem.yaml`.

## Скрипт

Yosys (прототип `synth.py` стенда):

```
read_liberty -lib <lib>
read_slang --no-synthesis-define --no-default-translate-off-format solution.sv --top <top> -G <P>=<v> …
synth -top <top> -flatten
tee -q -o latches.txt select -count t:$_DLATCH* t:$_DLATCHSR* t:$_SR_* t:$dlatch* t:$sr
tee -q -o check.txt check                       → комбинационные петли
rename <top> <top>__netlist ; write_verilog -noattr netlist_generic.v ; rename <top>__netlist <top>
dfflibmap -liberty <lib>
abc -liberty <lib>
hilomap -singleton -hicell LOGIC1_X1 Z -locell LOGIC0_X1 Z ; splitnets -ports ; opt_clean -purge
tee -q -o stat.json stat -liberty <lib> -json    → area, num_cells, num_cells_by_type
tee -q -o ltp.txt ltp -noff * t:DFF* t:SDFF* %u %d
write_verilog -noexpr -noattr netlist.v
```

OpenSTA (`sta -no_init -exit sta.tcl`):

```
read_liberty <lib> ; read_verilog netlist.v ; link_design <top>
create_clock -name clk -period <P> [get_ports <clock>]   # без порта clock: виртуальный клок
set_input_delay 0 -clock clk <входы, кроме клока>
set_output_delay 0 -clock clk [all_outputs]
set_driving_cell -lib_cell BUF_X1 <входы, кроме клока>
set_load <ёмкость DFF_X1/D = 1,14 фФ> [all_outputs]
report_checks -path_delay max ; worst_slack -max
```

`critical_path_ns = P − WNS` — одна формула для reg→reg, in→reg, reg→out и, с виртуальным клоком, in→out.

## Результаты

### Метрики эталонов

| Задача | Площадь, µm² | Ячейки | Триггеры | Крит. путь, нс | Худший путь | `logic_depth` |
|---|---|---|---|---|---|---|
| mux4 | 41,762 | 41 | 0 | 0,1722 | `sel[0]` → `y[3]` | 3 |
| carry-adder | 47,348 | 38 | 0 | 0,3868 | `b[0]` → `sum[7]` | 9 |
| counter-mod-n | 34,580 | 18 | 4 | 0,3174 | триггер → триггер | 3 |
| seq-detector | 31,920 | 15 | 5 | 0,1765 | триггер → триггер | 2 |
| sync-fifo | 1194,872 | 526 | 145 | 0,5917 | триггер → `rdata[0]` | 7 |

Порядок величин — «учебный» 45 нм, как ожидал ADR-0007. У seq-detector 5 триггеров: `synth` перекодирует автомат из 2 бит в one-hot (проход `fsm`).

### Детерминизм и время

| Машина | Запусков | Разных `metrics` / `stat.json` / `netlist.v` / `netlist_generic.v` | Yosys, с (мин–макс) | OpenSTA, с | Контейнер целиком, с |
|---|---|---|---|---|---|
| рабочая, WSL2, `runc` | 5 × 20 | 1 / 1 / 1 / 1 на задачу | 0,67–1,75 | 0,29–0,57 | 1,75–3,39 |
| VPS, `runc` | 5 × 20 | 1 / 1 / 1 / 1 | 0,41–0,62 | 0,19–0,30 | 0,98–1,55 |
| VPS, `runsc` | 5 × 20 | 1 / 1 / 1 / 1 | 0,81–1,38 | 0,30–0,44 | 1,58–2,18 |

Хэши всех четырёх файлов **одинаковы на обеих машинах и в обоих рантаймах** (300 запусков). Самая крупная задача, FIFO, синтезируется за 1,1–1,8 с вместе с STA — цель < 5 с выполнена с запасом.

### OpenSTA против `abc -D` и `sta`

- `abc -D 2000`, `-D 300` и `-D 100` дают **тот же нетлист**, что `abc` без `-D`: в Yosys 0.70 скрипт ABC для liberty заканчивается на `&nf` (`-D` передаётся в `&nf` и `retime`), без `buffer`/`upsize`/`stime`, поэтому ABC не печатает оценку задержки и на этих задачах не меняет картирование.
- `sta` Yosys считает задержки по `specify`-блокам и моделям `abc9`, liberty он не читает — к Nangate45 неприменим.
- Остаётся OpenSTA: 0,2–0,4 с на задачу, путь и задержки по таблицам liberty.

### Симуляция нетлиста

`netlist_generic.v` — нетлист после `synth` на внутренних вентилях Yosys: `assign` с выражениями и `always @(posedge clk)` на триггер. Тестбенч задачи инстанцирует `top` с параметрами (`#(.WIDTH(WIDTH))`), а у нетлиста их нет, поэтому модуль переименовывается в `<top>__netlist`, а этап добавляет обёртку `top` с параметрами и портами из `problem.yaml`. Обёртка проверяет, что тестбенч не переопределил параметр другим значением:

```systemverilog
module mux4 #(parameter int WIDTH = 8) (input logic [(2)-1:0] sel, …, output logic [(WIDTH)-1:0] y);
  if (WIDTH != 8) begin : apx_check_WIDTH
    $fatal(1, "netlist synthesized for WIDTH=8");
  end
  mux4__netlist u (.sel(sel), …, .y(y));
endmodule
```

| Проверка | Результат |
|---|---|
| 5 эталонов: нетлист тем же тестбенчем и сидом, группы `public` + `hidden` | все проходят, те же такты, что у RTL |
| Сборка нетлиста / RTL | 9–10 с / 9–10 с (рабочая машина, 2 CPU): нетлист стоит столько же, сколько ещё один `sim_full` |
| Нетлист, синтезированный при `WIDTH=4`, под тестбенчем с `WIDTH=8` | `$fatal` на элаборации — у Verilator это предупреждение `USERFATAL`, и `-Wno-fatal` этапа `sim` его глушит: сборка проходит, тест падает по ширине. С `-Werror-USERFATAL` — ошибка сборки |
| Подмена нетлиста: 25 случайных замен оператора в `assign` (`&`↔`\|`, `^`→`&`, снятие `~`) | **24 из 25 пойманы** тестами; оставшаяся замена эквивалентна после сброса (доказано `miter -equiv` + `sat -seq 40`; контрольная пойманная замена тем же способом даёт контрпример) |

### Решения, где синтез может разойтись с симуляцией

| Случай | RTL (`sim`) | Нетлист (`netlist_sim`) | Вывод |
|---|---|---|---|
| `unique case` без ветки для `sel = 3`, значение по умолчанию до `case` | **останов**: Verilator по умолчанию проверяет `unique` («unique case, but none matched»), нет `suite_end` | неверный ответ: синтез считает `sel = 3` безразличным (площадь 31,7 вместо 41,8) | ловится уже на `sim` |
| `priority if` без последнего `else`, значение по умолчанию | проходит | проходит | синтез не считает `priority` полным |
| неполный список чувствительности `always @(count)` | неверный ответ (скрытый тест) | проходит | Verilator соблюдает список; ловится на `sim` |
| блокирующие присваивания в двух `always_ff` (гонка) | неверный ответ в одной схеме, в двух других — как синтез | проходит / как RTL | порядок блоков у Verilator зависит от схемы; решения «проходит RTL, но не нетлист» собрать не удалось, страхует `netlist_sim` |
| `// synthesis translate_off` вокруг логики | проходит | с флагами — проходит; **без флагов** — 0 ячеек, неверный ответ | флаги нужны (precheck и так вырезает комментарии) |
| `` `ifdef SYNTHESIS `` | проходит | с флагами — проходит; **без флагов** — 0 ячеек, неверный ответ | флаги нужны (precheck и так запрещает препроцессор) |
| неполное присваивание в `always @*` | неверный ответ | неверный ответ | 8 латчей `$_DLATCH_*`, `select` их находит |
| неполное присваивание в `always_comb` | неверный ответ | неверный ответ | **латчей 0**: sv-elab строит комбинационную петлю `y = … ? y : …`, `check` пишет «found logic loop» со строкой решения |

## Выводы

1. **Метрики детерминированы побайтно** — на двух машинах, под `runc` и `runsc`, 300 запусков. Отдельной настройки потоков ABC не потребовалось.
2. **Синтез быстрый**: 0,4–1,8 с Yosys и 0,2–0,4 с OpenSTA на задачу; таймаут этапа 60 с (06 §2) избыточен для демо-задач.
3. **yosys-slang больше не плагин.** Проект переименован в sv-elab и с Yosys 0.67 встроен в Yosys: `plugin -i slang` не нужен, `read_slang` и флаги прежние. slang в Yosys 0.70 — тот же коммит, что в pyslang 12.0.0 этапа `precheck`, поэтому оба этапа разбирают код одной версией (R8). При обновлении нужно держать их вместе.
4. **«Латч» бывает двух видов.** Неполный `always @*` даёт латчи, неполный `always_comb` — комбинационную петлю. `forbid_latches` должен отвергать и то и другое; `check` указывает строку решения. В `synth` Yosys 0.70 есть `-latches error`, но петли он не ловит.
5. **`ltp -noff` проходит сквозь триггеры liberty** (он знает только триггеры Yosys): у счётчика получалось 15 вместо 3. Нужно исключить ячейки триггеров из выборки.
6. **Задержку даёт только OpenSTA.** `abc -D` в Yosys 0.70 не меняет картирование на этих задачах и не оценивает задержку, `sta` Yosys не читает liberty. Ограничения из ADR-0007 работают; формула `P − WNS` едина для всех видов путей.
7. **`fmax_mhz` для комбинационных задач бессмыслен** (5807 МГц у mux4): это обратная задержка in→out, а не частота. Для задач без порта `clock` UI показывает только задержку.
8. **Симуляция нетлиста работает и стоит одну сборку**: эталоны проходят, все неэквивалентные подмены пойманы. Обёртке нужен `-Werror-USERFATAL`, иначе несовпадение параметров синтеза и тестбенча превращается в непонятный «неверный ответ» вместо ошибки задачи.
9. **Пустой дизайн** (всё вырезано) — в `stat -json` нет ключа `area`; разбор должен считать площадь 0.

## Лицензия Nangate45 — новое обстоятельство

ADR-0007 исходит из «Nangate Open Cell Library License 1.0»: запрет бенчмаркинга, «not intended for commercial use». Но OpenROAD-flow-scripts (откуда берётся liberty) указывает версию **`PDKv1.3_v2010_12.Apache.CCL`**, загруженную с сайта Si2, и кладёт рядом `LICENSE` с текстом **Apache-2.0**. Silvaco (купившая Nangate) в 2019 году сообщала, что 45-нм библиотека была передана Si2 «under similar terms», то есть по Apache-2.0, как 15-нм. При этом заголовок самого `.lib` сохранил старое уведомление Nangate («provided pursuant to a License Agreement containing restrictions»).

Если 45-нм библиотека действительно распространяется по Apache-2.0, ограничения R15 (запрет сравнения с другими библиотеками, исключение в NFR-MAINT-07) снимаются. Решение юридическое — вынесено в открытые вопросы как ОВ-21; до ответа действует ADR-0007 как есть. Для T3.1a это ничего не меняет: рядом с liberty кладутся `LICENSE` и `README.md` из ORFS (версия и источник) и уведомление из заголовка liberty сохраняется.

## Рекомендации

- **T3.1a** (образ, профиль 2): Yosys из релизного `yosys.tar.gz` (CMake, `YOSYS_ENABLE_UNIT_TESTS=OFF`), без отдельного плагина; OpenSTA из `parallaxsw/OpenSTA` по коммиту с CUDD 3.0.0 (сборке нужен `libfl-dev`); liberty и `LICENSE` + `README.md` из ORFS по коммиту, sha256 в `versions.lock`. Тест образа: версия slang в Yosys совпадает с pyslang. Можно урезать образ (`share/yosys` без лишних techlibs) — по желанию.
- **T3.1b** (`synth`): скрипт выше; `forbid_latches` → `failed`/`compile` при латчах **или** петлях (`check`), с местом из сообщения; `logic_depth` — `ltp -noff` без триггеров liberty; `critical_path_ns = P − WNS`; `fmax_mhz` только при порте `clock`; пустой `stat` → площадь 0; `synth/v1` дополнить ячейками по типам для вкладки «Синтез» (по желанию). Порог времени — оставить 60 с.
- **T3.2** (`netlist_sim`): нетлист переименовывается в `<top>__netlist`, этап генерирует обёртку `top` с параметрами из `problem.yaml` и проверкой `$fatal`; сборка с `-Werror-USERFATAL`; несовпадение параметров — ошибка задачи (`error`), её ловит `judge validate` на эталонах. В `tests/security`: подмена нетлиста (замена оператора) и решения из `cases/` стенда.
- **T3.3**: метрики эталонов детерминированы — их можно сравнивать побайтно при смене профиля.
