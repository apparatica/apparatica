# Компоненты Apparatica · Bench

Соответствие «компонент макета → реализация». Листы с примерами: `screens/CmpA` – `CmpD` (светлая и тёмная тема). Токены — в `design/tokens.css`. Если у компонента перечислены состояния, нужны все.

Иконки только Lucide (`lucide-react`), штрих 2 px. Размер: 14 px внутри бейджей и строк, 16–18 px в кнопках и навигации, 20–22 px в пустых состояниях.

## Статусы (лист CmpA)

Один компонент `VerdictBadge` с пропсом `status`. Высота 26 px, радиус 2 px, шрифт 12.5 px / 500, иконка 14 px слева, внутренние отступы 0 10 px. Заливка — токен с суффиксом `s`, текст и иконка — основной токен.

| Статус | Текст | Иконка Lucide | Токены | Примечание |
|---|---|---|---|---|
| Принято | Принято | `circle-check` | `ok` на `oks` | |
| Неверный ответ | Неверный ответ | `circle-x` | `er` на `ers` | |
| Ошибка компиляции | Ошибка компиляции | `code-xml` | `er` на `ers` | |
| Предупреждения линта | Предупреждения линта | `triangle-alert` | `wn` на `wns` | решение принято |
| Превышен лимит | Превышен лимит | `timer` | `wn` на `wns` | время, память или объём вывода |
| Запрещённая конструкция | Запрещённая конструкция | `shield-x` | `er` на `ers` | |
| В очереди | В очереди · позиция N | `clock` | `in` на `ins` | |
| Выполняется | Выполняется · этап, время | `loader-circle` (вращается) | `in` на `ins` | |
| Отменено | Отменено | `circle-stop` | `tx` на `sf2`, граница `bc` | нейтральный |
| Внутренняя ошибка | Внутренняя ошибка | `octagon-alert` | `er`, контур 1.5 px, без заливки | отличается формой, не только цветом |

Компактный вид: квадрат 26 × 26 только с иконкой, смысл дублируется `title` и `aria-label`. Значение статуса никогда не выражается одним цветом.

## Конвейер проверки (лист CmpA)

Четыре блока: линт, симуляция, синтез, формал. Каждый — `PipelineStage` с названием и подписью (время или причина). Ширина блоков пропорциональна времени, у ещё не запущенных — минимальная. 8 состояний:

| Состояние | Иконка | Вид |
|---|---|---|
| Ожидает | `clock` | нейтральная рамка |
| Идёт | `loader-circle` | `ins`, граница `in`, подпись «идёт · 1,4 с» |
| Чисто | `circle-check` | `oks`, текст `ok` |
| Предупреждение | `triangle-alert` | `wns`, текст `wn` |
| Ошибка | `circle-x` | `ers`, граница `er` |
| Пропущен | `circle-minus` | пунктирная рамка, диагональная штриховка |
| Отменён | `circle-stop` | нейтральная, граница `bc` |
| Сбой платформы | `octagon-alert` | рамка `er`, без заливки |

## Сложность и теги

`DifficultyBadge`: высота 22 px, mono 11 px / 500, три столбика (высоты 4, 7, 10 px; заполнены 1, 2 или 3), затем слово. Easy — `e` на `es`, Medium — `m` на `ms`, Hard — `h` на `hs`. Hard фиолетовый, чтобы не читаться как ошибка.

`TagChip`: shadcn `Badge`, вариант outline, высота 20 px, mono 11 px, граница `bd`. Выбранный фильтр: граница и текст `ac`, фон `acs`. Чип со сбросом имеет иконку `x`.

## Карточка метрики (лист CmpB)

Состав: подпись (label-стиль, верхний регистр), значение (metric 26/34, mono), единица, строка сравнения словами, опорные числа. Цвет сравнения: лучше эталона — `ok` со стрелкой ↓, хуже — `wn` со стрелкой ↑, как у эталона — `mu`. Состояния: лучше, как у эталона, хуже, нет сравнения (подпись «сравнение появится после Submit»), скелетон, подсказка при наведении (shadcn `Tooltip`, фон `tx`, текст `sf`, максимум 210 px, появляется через 300 мс).

Метрики: задержка критического пути (нс, рядом эквивалентная частота), площадь (µm²), число ячеек, число триггеров. Значок µ не переводить в верхний регистр.

## Консоль (лист CmpB)

Mono 12.5 px / 19 px. Типы строк: разделитель этапа (`── lint ──`, цвет `mu`), информация (`mu`), успех (`ok`), предупреждение (`wn`), ошибка (`er`), ссылка «файл:строка» (`ac`, подчёркнута; клик вызывает `revealLineInCenter` в Monaco). Панель управления снизу: «Копировать» (`ghost`), переключатель «Прокрутка за выводом», кнопка «Вниз». Потоковый вывод: автопрокрутка включена по умолчанию, отключается при ручной прокрутке вверх. При обрыве стрима показываются строка о потере связи и состояние переподключения (см. `ResultStates`).

## Список тестов (лист CmpB)

Строка: иконка статуса, название теста, подпись. Состояния: пройден (`circle-check`, `ok`, время), выполняется (`loader-circle`, `in`), упал (`circle-x`, `er`, справа «такт N» mono), не запускался (`circle-minus`, `mu`), скрытые тесты (`lock`, подпись «откроются после Submit»). У упавшего теста раскрывается таблица «ожидалось / получено» и кнопка «показать на диаграмме» (см. `ResultTabs`).

## Контейнер временных диаграмм (лист CmpC)

Шапка 32 px: подпись «Волны», справа служебная информация («243 такта · FST 1,2 МБ»). Тело — iframe Surfer. 5 состояний: норма (курсор ошибки — пунктир `er`), загрузка (скелетоны), пусто («Волн пока нет»), ошибка («Не удалось загрузить волны» и кнопка «Повторить»), слишком большой файл (> порога, кнопка «Скачать FST). Цвета сигналов в Surfer: такт — `ac`, цифровые линии — `tx`, шины — `in` на `ins`.

## Строки рейтинга (лист CmpC)

Высота 34 px, границы `bd`. Призёры 1–3: номер и значение жирнее. Группа совпадающих решений: свёрнутая строка с диапазоном мест («5–7»), счётчиком и `chevron-right`; в раскрытом виде подстрока 28 px на фоне `sf2` с текстом «совпадает с решением #N». Своя строка: фон `acs`, левая полоса 3 px цвета `ac`, чип «вы». Разрыв между блоками: `· · ·`. Если своего места нет: строка «вашего места пока нет». Основная метрика колонки выделена жирным и стоит правее.

## Тепловая карта активности (лист CmpC)

Квадраты 14 × 14 px, зазор 3 px, радиус 2 px. 5 уровней: пустой — `sf2`, затем `h1` – `h4`. Сегодняшняя клетка обведена контуром 1.5 px цвета `tx`. Подсказка при наведении: «3 принятых · 12 октября». Состояния: данные, загрузка (shimmer), пусто («Пока нет принятых решений. Решите первую задачу, чтобы заполнить карту.»). Уровни нельзя различать одним цветом при чтении таблицей: в подсказке всегда есть число.

## Просмотр кода (лист CmpC)

Код только для чтения. Шапка с именем файла и режимом, справа «Копировать». Номера строк mono, `mu`, не выделяются. После копирования уведомление «Код скопирован» (в правом нижнем углу, исчезает само).

## Базовые контролы (лист CmpD)

Опираются на shadcn/ui, перекрашены токенами. Высота обычных элементов 30 px (на мобильных 44 px).

| Элемент | shadcn | Особенности |
|---|---|---|
| Кнопки | `Button` | основная: фон `ac`, текст `acx`; обычная: фон `sf`, граница `bc`; прозрачная; выбранная: `acs` + граница `ac`; недоступная — прозрачность 45%; загрузка — иконка `loader-circle`. Подсказка клавиш — `kbd` mono 10.5 px |
| Поле ввода | `Input` | граница `bc`, фон `ed`; фокус — контур 2 px `ac`; ошибка — граница `er` и сообщение с иконкой `circle-x` под полем; недоступно — прозрачность 50%, фон `sf2` |
| Поиск | `Input` + `Command` | иконка `search`, справа подсказка `/` |
| Флажок, переключатель, тумблер | `Checkbox`, `RadioGroup`, `Switch` | граница `bc`, выбранный — заливка `ac` и знак цветом `acx`; тумблер 30 × 16 px |
| Вкладки | `Tabs` | активная: нижняя линия 2 px `ac` и вес 500; сегментный переключатель — выбранный сегмент `acs` с нижней линией |
| Меню | `DropdownMenu` | пункты 28 px, активный — `acs`/`ac`, справа сочетание клавиш |
| Подсказка | `Tooltip` | фон `tx`, текст `sf`, тень `shadow-pop` |
| Уведомления | `Sonner` / `Toast` | левая полоса 3 px: `ok`, `wn`, `er`, `in` + иконка + заголовок и подпись + `x` |
| Пагинация | `Pagination` | квадраты 28 px, текущая — `acs` с границей `ac` |
| Аватар | `Avatar` | 20, 28, 40 px, инициалы, граница `bc` |
| Скелетон | `Skeleton` | shimmer через переменную `--shim`; при reduced-motion без анимации |
| Палитра команд | `Command` в `Dialog` | поиск по задачам и действиям, группы с подписями, сочетания клавиш справа |

## Темы редактора Monaco (лист DsMonaco)

Готовый код — `design/monaco-themes.ts`. Волнистое подчёркивание ошибки — `er`, предупреждения — `wn`; обе подчёркивания сопровождаются иконкой на полях и записью в панели диагностики, не только цветом.

## OG-карточка

Размер 1200 × 630, всегда в тёмной палитре. Состав: словесный знак, бейдж сложности, вердикт «Принято», название задачи (84 px), метрики (задержка, площадь, ячейки, триггеры), место «5 из 304», ник автора (по брифу). Рендерится на сервере (например, `next/og`), поэтому цвета нужно передавать значениями, а не `var(--…)`: берите hex из тёмного блока `tokens.css`.
