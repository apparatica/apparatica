# backend

FastAPI-приложение и ингестор результатов Apparatica (модульный монолит, пакет `apparatica`).

Запуск: `poetry -C backend run apparatica serve --reload`, миграции: `poetry -C backend run apparatica migrate`.

Устройство — [docs/architecture.md](../docs/architecture.md), разработка — [docs/development.md](../docs/development.md#бэкенд-apparatica), настройки — [docs/configuration.md](../docs/configuration.md).
