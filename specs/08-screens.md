# 08. Экраны и состояния (сверка с макетами)

Макеты: `brief/apparatica-handoff/screens/<Имя>.{light,dark}.png`, компоненты — `components.md`, токены — `design/tokens.css`. Визуал берётся из макетов; поведение — из этой спецификации. «Без макета» — собирается из существующих компонентов и сверяется с дизайном позже.

## 1. Маршруты

Маршруты из `HANDOFF.md` принимаются с уточнениями.

| Маршрут | Экран | Макет | Фаза | Рендер |

| `/problems` | Каталог | `Catalog`, `MobCatalog` | Ф1 | SSR, фильтры в URL |

## 2. Оболочка

Шапка: знак и «Apparatica», хлебные крошки, «Быстрый поиск» (Ctrl+K открывает палитру команд), аватар или «Войти». Левая рейка: «Задачи», «Рейтинг», «Дашборд»; снизу — профиль. Строка состояния только на странице задачи: режим, сложность, «Автосохранение», язык, «Стр, Стлб». Переключатель темы — в меню пользователя и в палитре; тема по умолчанию — системная, выбор хранится в cookie (чтобы SSR не мигал).

На ширине < 640 px — нижняя навигация из 4 разделов: Задачи, Рейтинг, Дашборд, Профиль.

## 3. Страница задачи — состояния панели результатов

| Состояние | Макет | Конвейер | Баннер / тело |
|---|---|---|---|
| Пусто (ни одной отправки) | `BenchEmpty` | все «ожидает» | подсказка Run/Submit с клавишами |
| В очереди | `BenchQueued` | все «ожидает» | «В очереди · позиция N · ≈ M с», «Отменить» |
| Выполняется | `BenchRunning` | текущий «идёт · 1,4 с», остальные «ожидает» | консоль в стриме, heartbeat долгого шага |
| Неверный ответ (Run) | `Bench` | sim «ошибка · тест 7 из 32», дальше «пропущен» | «Неверный ответ · Run на открытых тестах», «Показать на диаграмме» |
| Неверный ответ с волнами | `BenchWave` | то же | вкладка волн с курсором |
| Принято (Submit) | `BenchAccepted` | все «чисто» | «Принято · место N из M», действия; вкладка «Синтез» |
| Принято с предупреждениями | без макета (вариант `BenchAccepted` с `wn` у линта) | lint «предупреждение» | баннер «Принято» + «N замечаний линта» |
| Run пройден | без макета (вариант `BenchAccepted` без рейтинга) | sim «чисто» | «Открытые тесты пройдены · отправьте Submit для полной проверки» |
| Ошибка компиляции | без макета; баннер по образцу «Неверный ответ» | lint/precheck «ошибка» | первая ошибка с «file:line», переход в редактор |
| Запрещённая конструкция | без макета; баннер по образцу | lint «ошибка» | «$system в строке 12 запрещён: …» со ссылкой на правила |
| Отменено | `ResultStates` | текущий «отменён», дальше «не запускался» | «Отменено», «Смотреть новую» |
| Превышен лимит вывода | `ResultStates` | sim «лимит вывода» | «Скачать начало лога» |
| Превышен лимит времени/памяти | без макета; как лимит вывода | «лимит времени» | совет по вероятной причине |
| Внутренняя ошибка | `ResultStates` | «сбой платформы» | «Это не вина вашего решения», «Повторить», «Сообщить», код сбоя |
| Обрыв стрима | `ResultStates` | без изменений | «Связь с логом потеряна · переподключение через N с», «Подключиться сейчас» |
| Лимит почти исчерпан / исчерпан (гость) | `Guest` | — | счётчик / панель с таймером |
| Загрузка страницы | `Loading` | скелетоны | скелетоны условия, редактора, панели |

Вкладки панели результатов: «Консоль», «Тесты N/M», «Временные диаграммы», «Синтез» (Ф3), «Формал» (Ф5). Вкладки недоступных фаз скрыты флагами. Открытая по умолчанию вкладка: при ошибке теста — «Консоль» (как в макете), при Accepted — «Синтез».

## 6. Известные расхождения с макетами

| Макет | Расхождение | Решение |
|---|---|---|
| Контейнер волн | подпись «VCD», «Скачать VCD» | везде FST |
| `BenchWave`, контейнер волн | ось в тактах (139…147), курсор — пунктир `er`, в шапке «−», «+», «во весь экран» и «Открыть трассу целиком» | ось Surfer — время FST: номера тактов — в шапке («Такты 0–46») и в метке «такт N» у курсора; курсор и метка — сплошные линии цвета `er` (Surfer не рисует пунктир); масштаб и прокрутка — колесом в самом Surfer, в шапке «К расхождению», «Всё окно» и «Скачать FST»; «Открыть трассу целиком» появится с аккаунтами (Ф2, FR-WAV-05) |
| `ModalsA` | ссылка вида `apparatica.app/s/2917` (числовой ID) | ID решений — UUID; короткая ссылка `/s/<base62 от UUID>`; домен — `apparatica.app` (ОВ-14), в коде — из конфига `PUBLIC_BASE_URL` |
| `SolutionLB`, `GlobalLB`, `Dashboard` | формула очков, «+5 за неделю» | формула утверждена (ОВ-4), вычисляется по конфигу; данные на макетах вымышленные |
| `LeftTabsA` | «Мои отправки»: причина «sync_fifo.sv:18» у ошибки компиляции; «Отправки хранятся без ограничения по времени» | у ошибки компиляции и запрещённой конструкции — «строка N: сообщение» первой ошибки; гостю — пояснение, что список хранится в браузере, а код и результаты — на сервере до конца срока хранения (ОВ-13) |
| `LeftTabsB` | замок у «Решения» и «Эталон» | соответствует решению ОВ-2; у задач с `reference.visibility: public` замка у «Эталона» нет |
| Конвейер | 4 блока; в спецификации есть `precheck` и `netlist_sim` | `precheck` отображается внутри блока «Линт», `netlist_sim` — внутри блока «Синтез» (подпись «проверка нетлиста» во время выполнения и при ошибке) |
| Статусы | `accepted_with_warnings` подписан «Предупреждения линта» | при замечаниях только от линта — как в макете; если есть неопределённые свойства формала — «Принято с замечаниями» (без макета, тот же бейдж) |
| Рейтинг | места уникальны | равные метрики делят место (1, 2, 2, 4) — несколько строк с одинаковым номером |
| Статусы | нет статуса для «не синтезируется» | решено (ОВ-9): «Ошибка компиляции», ошибка у блока «Синтез»; новый бейдж не нужен |
| `Catalog` | сортировка «по номеру» | добавлены сортировки по сложности и проценту принятых |
| `MobTask` | «прислать ссылку на почту» | для гостей — «Скопировать ссылку»/Web Share, письмо — только вошедшим (решение ОВ-15) |
| Гостевой дашборд, мобильные рейтинги и профиль, страница настроек, email-вход, юридические страницы | нет макетов | собрать из компонентов, пометить «без макета», сверить с дизайном |
