# ADR-0005. Допустимое подмножество SVA

- Статус: Предложено (финализируется по итогам спайка S1)
- Дата: 2026-10-24
- Связано: бриф §5; FR-FRM-*; 06 §4; 07 §2.5

## Контекст
Формальные проверки — только свойства автора задачи через SymbiYosys, без эквивалентности эталону. Открытый Yosys поддерживает SVA ограниченно (полная поддержка — в коммерческом Verific). Решение пользователя читается через yosys-slang; свойства должны читаться той же связкой, иначе разные фронтенды по-разному поймут дизайн.

## Решение (рабочее, до S1)
Авторам разрешено гарантированно работающее ядро:
- immediate `assert`, `assume`, `cover` внутри `always_ff @(posedge clk)` и `always_comb`, с метками `p_<name>:`;
- `$past(expr[, N])`, `$stable`, `$rose`, `$fell`, `$initstate` (если поддерживается), флаг `f_past_valid`;
- вспомогательная checker-логика на синтезируемом SV (счётчики, теневые модели, FIFO-scoreboard);
- подключение через `bind <top> <checker> u_chk (.*)`;
- ограничения окружения через `assume`.

Расширенное подмножество, **если S1 подтвердит поддержку в yosys-slang + SBY**:
- конкурентные `assert property (@(posedge clk) disable iff (!rst_n) a |-> b)` и `|=>`;
- фиксированные задержки `##N` в последовательностях;
- `s_eventually`/`always` — нет (не ожидается).

S1 выдаёт тестовый корпус (`toolchain/tests/sva/`) — по одному свойству на конструкцию, с ожидаемым результатом (доказано / нарушено на глубине N). Корпус становится регрессией образа тулчейна: обновление yosys-slang не должно молча менять семантику.

`judge validate` проверяет, что свойства задачи используют только разрешённые конструкции (по синтаксическому дереву pyslang).

## Последствия
- Авторы пишут свойства в стиле «immediate + $past», хорошо известном по SymbiYosys; это многословнее конкурентных свойств, но предсказуемо.
- Решение пересматривается при каждом обновлении профиля тулчейна.

## Альтернативы
- `read -formal` (родной фронтенд Yosys) для свойств и `read_slang` для решения — два фронтенда в одном проекте, риск несовместимостей; допустимо как запасной вариант для чтения только файла свойств, если S1 покажет, что yosys-slang не читает immediate-утверждения с `$past`.
- Verific — проприетарный, противоречит принципу open source.
- Формал через эквивалентность эталону — исключено брифом.
