Регистр `count` и комбинационный `wrap`, который сам служит условием перехода в 0: одно сравнение `count == N − 1` используется дважды, и выход не расходится со счётом.

Порядок веток задаёт приоритеты: сброс важнее счёта, переход в 0 — частный случай счёта при `en = 1`. Константа `LAST` приведена к ширине счётчика (`W'(N - 1)`), чтобы сравнение шло без расширения до 32 бит и без предупреждения линта о ширине.
